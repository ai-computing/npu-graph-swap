# Contributing

This repository follows the organization's workflow: <https://github.com/ai-computing/.github/blob/main/CONTRIBUTING.md>.

Additions: every experiment has an Issue with its hypothesis and a record under `experiments/` (date, hardware, SDK
versions, commands, raw numbers, conclusion). Negative results are recorded the same way. Vendor runtimes and engine
code (Optimus Prime) are not modified here; needs found here become feature requests.
